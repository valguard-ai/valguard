# Contributing (Phase C stub)

Development for the OSS CLI currently happens in the ValGuard monorepo on branch `feature/oss-phase-c-prep` (bridge architecture). See [docs/opensource-cli-phase-c.md](../../docs/opensource-cli-phase-c.md) in the monorepo.

When this directory becomes the public repository root:

- Open PRs against `main`.
- Run `go test -race ./...` and conformance fixtures before review.
- Follow Apache-2.0 licensing for new files.
